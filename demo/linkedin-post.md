## Option A — the story (recommended)

Every project I costed started the same way: a BOQ, a budget breakdown, a set of
payment assumptions, and a Primavera schedule. And then [TIME] of building the
cashflow workbook by hand — tab by tab, formula by formula, for every currency on
the job.

Do that across enough projects and you learn two things. It is slow. And no matter
how careful you are, hand-built workbooks drift from each other.

So I built a tool that does it.

Four files in. One click. Out comes the full cashflow baseline:

→ 18 sheets
→ 3 currencies (USD, EGP, EUR)
→ Cash In, Cash Out, monthly Cashflow, Summary and EQU tabs
→ 79,041 live formulas, wired the way we actually build them
→ 2,229 schedule activities mapped to their cash milestones

It runs entirely in the browser. No install, no server, no project data leaving
the laptop — which matters when the input is a live commercial budget.

The demo below runs on anonymized sample data, but the structure is exactly what
we use on real substation projects.

Cost control doesn't get less rigorous when you automate it. It gets more
consistent.
